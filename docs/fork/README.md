# Fork notes (johnnymo87/goose)

This branch is upstream goose plus the fork's patch stack, one commit per patch.
To move the stack to a new upstream release, follow the upgrade brief at
[fork-main: docs/fork/UPGRADING.md](https://github.com/johnnymo87/goose/blob/fork-main/docs/fork/UPGRADING.md).
That brief also lists, for each patch, who depends on it and which tests in the patched
release workflow cover it.
